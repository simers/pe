# Private Equity — Course Handbook, LBO Model & Analytics

A self-study private-equity course built as an interactive tutorial: a print-ready
**handbook**, a fully integrated **LBO model** (the illustrative *Cascade Components*
deal), and a small **analytics** package. Course structure follows the syllabus of the
Wharton Online & Wall Street Prep Private Equity Certificate Program; all content here is
independent and was generated by Claude (Anthropic) as an interactive tutor, directed and
reviewed by Simer Sawhney (Co-founder, Voatz Inc.).

> **📄 Read the handbook:** [`pe_course_handbook.pdf`](pe_course_handbook.pdf) — the
> rendered PDF is committed to the repo, so once pushed it has its own URL:
> `https://github.com/<user>/pe/blob/main/pe_course_handbook.pdf` (GitHub's viewer) and
> `https://raw.githubusercontent.com/<user>/pe/main/pe_course_handbook.pdf` (direct file).
> For the cleanest link, enable **GitHub Pages** (Settings → Pages → deploy from `main`)
> and it's served at `https://<user>.github.io/pe/pe_course_handbook.pdf`.

> Educational use only — not investment advice. All *Cascade Components* figures are
> illustrative; cited third-party facts should be verified against their original sources.

## What's in here

| File / folder | What it is |
|---|---|
| `pe_course_notes.md` | **Source of truth** for the handbook — every lesson, in Markdown. Edit this, then rebuild. |
| `build_handbook.py` | Generates `pe_course_handbook.pdf` (+ `.html`) from the notes: inserts SVG figures + the Excel snapshots, auto-numbers a table of contents, renders via headless Chromium. |
| `pe_course_handbook.pdf` | The rendered handbook (the shareable deliverable). |
| `pe_course_handbook.html` | Intermediate render (regenerable; safe to delete/ignore). |
| `snap_*.png` (×6) | Excel-tab snapshots embedded in the handbook (income statement, EBITDA bridge, balance sheet, sources & uses, debt schedule, returns). |
| `build_model.py` | Builds the LBO model workbook from scratch (reusable, auditable). |
| `Cascade_Components_LBO_Model.xlsx` | The integrated 8-tab LBO model (Assumptions → EBITDA Bridge → IS → BS → Sources & Uses → Debt Schedule → Returns). |
| `pe_analytics/` | Small Python package: QoE forensics, comps, DCF, forecasting demos. Runs `python3 -m pe_analytics.run_demo`. |
| `pe_course_progress.md` | Module-by-module progress tracker. |
| `pe_course_transcript.md` | Dialogue reconstruction (not always current). |

**Layout note:** the files are intentionally kept **flat** (not nested in subfolders)
because `build_handbook.py` reads `pe_course_notes.md` and the `snap_*.png` files from its
own directory, and `build_model.py` writes the `.xlsx` to its directory. Keeping everything
together means both scripts run with no path changes.

## Rebuilding

Requirements (see `requirements.txt`):

```bash
pip install -r requirements.txt
playwright install chromium      # one-time, for the PDF renderer
```

Rebuild the model, then the handbook:

```bash
python3 build_model.py           # -> Cascade_Components_LBO_Model.xlsx
python3 build_handbook.py        # -> pe_course_handbook.pdf (+ .html)
```

Or use the convenience wrappers (they do the same thing):

```bash
./build.sh --install             # first time: installs deps + chromium, then builds
./build.sh                       # rebuild model + handbook
./build.sh handbook              # rebuild just the handbook
# or, with make:
make install                     # one-time deps
make                             # rebuild everything
make clean                       # remove regenerable artifacts (.html, __pycache__)
```

The handbook builder prints a line like
`PDF written -> pe_course_handbook.pdf (NN pages; TOC converged in 2 pass(es))`.
"0 headings unresolved" means the table of contents mapped every heading to a page.

### Regenerating the Excel snapshots (only if a model tab changed)

The `snap_*.png` images are pictures of the model's tabs. If you change `build_model.py`
and want the handbook to show the new tab, re-render the workbook to PDF and crop the
relevant page. (In the authoring environment this was done with LibreOffice headless +
`pdftoppm` + Pillow; any "spreadsheet → PNG" workflow is fine as long as the output
filenames stay the same.)

## The Cascade Components model (base case)

Illustrative middle-market specialty industrial manufacturer, founder retiring.
Entry 9.0× × $58M EBITDA = $522M EV, 5.0× leverage; 5-year hold; exit 9.0×.
Result: **~2.17× MOIC / ~16.8% IRR**, with value creation split **67% EBITDA growth /
33% debt paydown / 0% multiple expansion**. Recalculate after any edit and confirm the
formula-error count is 0.
